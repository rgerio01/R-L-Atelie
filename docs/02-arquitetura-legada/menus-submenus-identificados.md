# Menus e Submenus Identificados

## Fonte

Este mapa foi extraido de:

- `Ger\Dados\Nivel.DB`, pela copia readonly em `MOD`;
- strings internas dos executaveis principais;
- arquivos gerados `menus-permissoes-niveldb.csv` e `menus-strings-executaveis.csv`.

## Confiabilidade

Os itens vindos de `Nivel.DB` sao os mais confiaveis para o `LavSoft`, porque representam rotinas usadas no controle de permissao.

Os itens vindos das strings dos executaveis indicam telas, botoes, captions e handlers, mas ainda precisam ser validados abrindo o sistema em homologacao.
